牌面候选来自[公开数字化档案](https://steamcommunity.com/sharedfiles/filedetails/?id=3064722448)。该档案同时含民间改版，不能把所有组件直接混入原版规则。核验清单仅收录与目录对应的候选；下载成功和哈希匹配仅确认文件完整，规则核验须同时具有原规则书或官方说明。

扫描原件和辅助 OCR 位于 `.data/sources/oripathy/`，不加入公开 Git，也不加入生产素材目录。核心指挥塔与本体图集共用图源，其数量、初始布置及效果需要和扩展规则书一起核对。

## 复核研究缓存

```powershell
python tools/research-oripathy.py --check
```

缺少缓存时，在有网络的环境中运行 `python tools/research-oripathy.py`。工具只获取清单中的图像，验证大小、PNG／JPEG 文件头和 SHA-256；哈希变化会直接报错，防止改版图像替换已有证据。工具不执行下载档案中的脚本。

## 接入前的规则核验项

这些问题决定合法行动、费用、结算顺序和测试预期，分别登记在清单的 `review.questions`：

1. **人数与开局准备。** PRTS 标为 3–4 人，公开教程介绍标为 2–4 人；需核对原规则书及两人变体。企业家分配、起始设施、阿米娅加入、初始手牌裁剪和牌池替换也需要原文。
2. **企业家抉择。** 第一、三、五、七回合相对角色盖放、起始玩家更替和红区开放奖励的顺序，以及抉择 A／B 面的选取与保留。
3. **设施叠放。** 全体玩家的叠放费用、合法设施限制、下层设施分数和样式标记处理；马丁的替代支付与入场效果分享。
4. **长途移动。** 费用、距离、中途节点、其他城市阻挡，以及清除、探索、放置影响力的先后顺序。
5. **新增符号与持续能力。** 战术行动、帮派影响力、岩蹄安保、招募替换和多种持续触发的原文说明。

## 工程接入边界

首页建房预期提供基础版、企业扩展和《感染者》三种配置。《感染者》需包含企业扩展；实际人数限制由核验后的原规则确定。服务端独立校验配置，房间与对局分别保存扩展标识，既有存档按原规则包继续。

完整规则核验后，再将具名效果处理器、私有选择、骰子随机状态、持续能力、地图标记、城市叠层及测试接入生产规则包。清单的 `productionEnabled: false` 是研究登记信息，现有首页与对局规则保持原有可玩配置。

# 多选与一次确认

角色放回卡盒、连续分配资源、连续支付基础资源可先搭配全部项目，再一次确认。角色牌沿用页面下方的扇形手牌，已选牌轻微上提并显示数量；再点一次撤选，选满后启用确认。资源使用配件图标和数量加减按钮。

关掉选择窗口或暂时返回房间大厅只改变界面，不提交选择。确认之前刷新会重新展示服务器保存的待选项；确认后的结果、房间版本和操作回执一并持久化，刷新或服务重启后继续。

## 规则与通信

- 玩家视图的 `decision.batch` 只向选择者提供剩余数量、项目上限与说明。原有逐项 `choose` 指令继续支持，人机沿用原有决策方式。
- `choose-many` 携带 `optionIds`，必须恰好选满剩余数量。退回角色不能重复；资源可以重复，但支付不能超过持有量。服务端校验行动者、数量、项目、房间版本与请求编号。
- 每一项仍调用原有规则校验，并在副本中按顺序结算。全部成功才生成一次状态版本、保存并广播；中间任何项目失效会拒绝整组，不留下部分结果。
- 剩余数量由存档内的后续步骤推导，兼容已经逐张退回一部分角色的旧存档，两套规则版本保持不变。
- 补充市场、跨玩家决定及中间会出现新选择的效果按原规则逐步执行。异客持有可替代支付的标记时，保留其支付选择，不把抵扣决定合并掉。

## 地图与页面返回

起始资源点单击预览、双击直接落城；键盘 Enter 也可落城，旁边保留“在此落城”按钮。城市短暂下落、压缩回弹并扬尘，随后展示探索事件。减少动态模式直接显示结果；刷新已有城市不重播落地。

棋桌的“房间大厅”按钮返回同一房间的席位概况，仍保持联机，可点“返回棋桌”继续。房间再返回联机大厅时保留房间码与席位凭证，重新加入同一房间不会多占席位。共用弹窗提供“返回”，嵌套详情返回上一窗口并恢复焦点。

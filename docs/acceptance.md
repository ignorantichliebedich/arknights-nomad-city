- 受控中局浏览器场景覆盖四种持续角色、暂存设施、剩余标记及十二格城市；秘密企业选择场景确认牌面预览不改变状态版本，关闭预览后仍能正常选择。
- 受控科室浏览器场景分别验证 2、3、4 人企业等级表、只读科室预览、共享激活科室、切换奖励及刷新恢复，覆盖长昵称和 1366 像素页面宽度。
- 正式扩展整局浏览器场景从自然建房、独立浏览器入座及准备开始，完成 2、3、4 人八回合，核对全部席位的最终得分与赢家并刷新恢复；二人、四人覆盖从真实抽选池选中莱茵生命、激活结构科及后续企业升级。标记耗尽后继续选择其他合法主要行动。
- 城市详情展示公开弃牌和退役角色；浏览器验证 W 的完整策略与计谋文本，并确认初始秘密裁剪角色不会出现在退役列表。详情弹窗具备可访问名称，Escape 逐层关闭角色详情与城市详情。

自动验收的命令为 `pnpm check`、`pnpm test`、`pnpm assets:check`、`pnpm build`、`pnpm test:e2e`。浏览器失败保留截图与 trace，位于 `test-results/`，可用 Playwright 的 `show-trace` 阅读。

## 验收环境注记

本机 Playwright Firefox 下载构建缺少 `mozglue` 外部程序集清单，Windows 事件日志报告 SideBySide 启动错误。验收使用项目研究缓存内的浏览器副本，并补齐 [Mozilla 原始清单](https://searchfox.org/firefox-main/source/mozglue/build/mozglue.dll.manifest)。该修复仅用于本机测试工具，游戏运行无需修改朋友浏览器。

目标服务器部署验收需要安装 Docker；本机交付包含部署配置与备份恢复说明。

受控界面测试会密集建立四人房间，测试夹具遇到现有每分钟 60 次建房/入房限制时等待重试，服务限制保持原值。Firefox 全屏模式优先处理 Escape 的退出全屏行为，跨浏览器全屏窗口验证使用窗口关闭按钮；普通窗口的逐层 Escape 关闭另行验证。

# 规则证据与配件登记

规则包：`founders-2023.1`。采用《铸基者》原版说明书与对应牌面，企业扩展包含八家原版企业及三张莱茵生命科室板。

## 原始出处

1. [官方桌游页面](https://ak.hypergryph.com/boardgame_nomadcity/)：产品与规则入口。
2. [PRTS 资料页](https://prts.wiki/w/游城拓荒：铸基者)：配件数量及角色资料交叉核对。
3. [公开社区数字化模组](https://steamcommunity.com/sharedfiles/filedetails/?id=3064722448)：Jakobs 上传的原牌扫描及原规则书。模组同时含民间改版，使用前逐项对照。
4. [原说明书扫描](https://steamusercontent-a.akamaihd.net/ugc/2282825689394632887/8F1D80001580DF5B3F528E7B80302B646C2AF857/)：28 个 PDF 页；印刷页码等于 PDF 页序减 2。SHA-256：`51bd7968a71fab1f8ca98784e33d5ef2366b1b1102c7a936fd54b30ff43cc326`。

原说明书在本地研究缓存 `.data/sources/rules-reference.pdf`。另一份四页文件是《大拓荒周报》，登记为 `newspaper.pdf`，用于背景参考。素材来源、裁切坐标、文件尺寸及哈希在 `assets/manifest.json`；实体数量和可读牌面数据在 `assets/catalog.json`。

[官方《拓荒指南——企业家定制版》中篇](https://i0.hdslb.com/bfs/new_dyn/25647499a17c66956ecf6db4e729b413161775300.jpg) 提供清晰的城邦工业区牌面，确认折扣按颜色而非设施名称计算。源图 SHA-256 为 `2929154c334dd040fab7a2eefe5e35f8ff59b4dc4407bb9ab680a8327716beac`；裁切证据位于 `.data/sources/official-guides/industrial-original-detail.png`。对应测试覆盖同色多名称、同类多颜色、三色上限和彩色排除。

## 出处差异注记

`rhine-original-labs`：原版科室为工程科、防卫科、结构科，奖励在 2–5 级升级时生效，换科室时仅操作者结算奖励。公开模组提供的人力、业务、科学科室属于民间改版。另一份英文数字化模组沿用同一组图像，不能作为独立确认。

工程科全部四档奖励由印刷页 15 的原配件图确认；防卫科全部四档奖励由 [官方《企业刷分》指导图](https://i0.hdslb.com/bfs/new_dyn/59e6dbf4987dae8a97decab6b965deca161775300.jpg) 确认；结构科由正式实物高清开箱确认。逐档数据、原文、来源哈希和图像证据登记在 `assets/original-labs.json`。

结构科实物证据：2024 年 1 月发布的 [棋鼓相当开箱视频约 7:20](https://www.youtube.com/watch?v=IVr7s998U0c&t=440s) 展示三张原版科室板正面。公开播放器正常提供 1080p；原尺寸帧位于 `.data/sources/public-video/youtube-IVr7s998U0c/frame-440.png`，实际时间 440.812479 秒，SHA-256 为 `ff34b0379607ca411298e58875f0bc6b0968926fb588d5dc0fb61a5e016b81e1`。结构科二级获得三源石、三级获得一分、四级支付三源石获得一至纯源石；五级降低一级该企业合作等级，并获得该等级的奖励，四级费用仍由玩家选择支付。该帧中工程科、防卫科的可见奖励与原说明书及官方指导图一致；相邻原始帧、实际时间及辅助识别记录随研究缓存保存。

[Mr.box 实物开箱约 8:59](https://www.bilibili.com/video/BV11v411c7Um/?t=539) 提供独立的结构科正面镜头；保存整帧及研究裁切，和高清来源交叉核对。其他已检查的开箱、教程、官方配件主图及玩家对局照片，按原文件和公开网址保存在 `.data/sources/public-video/`、`.data/sources/public-images/`。测试样本视频、模组改版和正式实物分别登记。

工程科、防卫科已接入规则引擎，使用对局级 `activeLab` 保存所有玩家共用的激活科室。切换仅给操作者当前等级奖励，后续升级按新科室结算；付费选择可跨刷新恢复。工程科四级先支付三源岩再正常建设，五级支付一至纯源石后仅免费建设供应区原价不超过二十三金券的设施。防卫科三级的替换与移动、四级两次放置或移除、五级金券兑换至纯源石均有对应场景测试。

2026-10-14 的独立档案核对：公开 [2024 年测试体验版](https://steamcommunity.com/sharedfiles/filedetails/?id=3110530272) 保存了三张科室候选牌的独立图像引用，档案中牌组编号为 10400、10200、10300。三个牌面公开图源及该档案的规则书图源返回 404；公开预览仅展示宣传主图。另核对 `3168777587`、`3359667241`、`3359729814` 三份快照，其科室图像引用与现有民间改版一致。原档案、来源哈希和引用记录保存在 `.data/sources/workshop-candidates/`，可供新来源到达后继续交叉核对。

三张原版科室的逐档奖励接入正式规则包，建房可启用完整八企业扩展。二人各从四张候选选两家初始企业，三、四人各从两张候选选一家；三人另从未抽取的企业选一家公共企业，按照印刷页 17、23 处理。基础版可独立运行。

所有民间额外设施、额外样式、感染者扩展和改版科室均放在研究缓存中，不进入生产运行目录。

## 结算修正与交互核验

- 罗德岛二级的金券数量在放置完成后读取，包含此次新增的航道影响力。无法部署时按仍在场上的航道影响力结算。
- 玛恩纳使全员升级时，奖励从操作者开始按顺时针结算；操作者已经满级也可提升其他尚未满级的玩家。
- 山选择的企业已经满级时，提升操作按“尽量执行”跳过，仍可触发该企业特效，保留已支付的角色费用。
- 采集确认前可撤回单个资源点或清空选择；移除不再需要的路径，保留连接其他已选资源点的共用航道，确认前不收取路费或发放产出。
- 公开玩家视图提供可用标记数量，计入影响力、样式、合作企业及持续角色占用；持续角色和暂存设施同时显示在自己的行动区域与公开城市详情。
- 企业、角色、事件及建设选择中的牌面预览为只读操作，不提交对局指令；实际选择再由服务端裁定。指令按字段内容匹配合法意图，不受 JSON 字段顺序影响，附加效果字段会被拒绝。
- 合作企业表展示所有玩家的公开等级，按玩家颜色和符号区分；科室详情从同一份已核验奖励数据生成，展示所有玩家共享的激活科室及逐档费用。

## 增加或修正规则

1. 保存原规则书页码或对应原牌面，记录来源及文件哈希。
2. 先确定费用、时机、信息可见性和次数限制，再修改数据或具名处理器。
3. 使用公共 `applyCommand` 入口写回归场景，同时验证等待选择的 JSON 恢复。
4. 更新规则版本、配件目录、素材清单；既有房间使用其原规则版本继续。

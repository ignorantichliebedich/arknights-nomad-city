# 手机棋桌

手机访问同一游戏入口和房间地址，沿用原有席位。棋桌按实际可见窗口高度排版，完整显示地图，无需手动缩放或拖动镜头。横屏时资源与回合栏并排，点击“回合与终局计分”查看官方计分配件。底部保留扇形手牌；“配件盘”查看玩家、城市、设施与合作企业。手机以顶部头像及大总统标志替代大幅立绘，让操作入口保持可达。

首次点击“全屏体验”时先请求文档全屏，再尝试锁定横屏。之后可在顶部再次开启或退出全屏。退出时释放本次方向锁。转屏和浏览器工具栏高度变化会重新计算棋盘尺寸，保留席位、已选牌和待确认操作。

部分手机浏览器不提供文档全屏或方向锁。此时继续使用适配后的窗口布局，竖屏时提示横放手机；手动横放后棋桌自动调整。窗口适配不会将页面状态冒充为系统全屏。浏览器能力与授权决定实际转向行为，参考 [Fullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen) 和 [Screen Orientation](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)。

## 触控操作

- 单指点选手牌后确认秘密盖放，或在同一张牌上连续轻点两次直接盖放；手牌按钮展开或收起，已选牌保留。
- 地图单击合法空位预览部署，双击直接放置；双击可探索资源点直接支付路费并探索，事件结果仍由玩家选择。
- 放置确认使用棋盘内的紧凑底部面板，回合条保持可见；收起扇面时只留手牌入口，避开角色能力按钮。
- 城市拖到合法停靠点，松手即支付并移动；影响力拖动继续保留预览确认。按钮与键盘操作也保留。
- 地图镜头固定完整展示。双指手势取消未松手的棋子拖动，不缩放地图，也不代替玩家落子；桌面端继续支持镜头缩放和平移。
- 首页许可、弹窗和配件盘使用“上一页／下一页”查看长内容，页面与窗口不需要手动滑动。翻页保留一段重叠内容，使跨页文字和按钮在相邻页完整可见。键盘焦点可自动进入对应内容页。
- 房间页同时显示席位及准备、开局按钮；“拓荒档案”和“招募设置”按需打开。
- 页面适配刘海安全区，输入字号至少 16px；不禁止用户缩放页面。

## 验证

运行 `pnpm build` 后执行 `pnpm test:mobile`。测试使用临时数据库和 3011 端口。

音乐场景使用本机导入的五首原始音乐，验证播放、切歌、曲终接续、前后台状态和加载失败恢复。执行前使用 `pnpm music:import`；缺少私人音乐原件时，该组真实曲目检查会明确跳过。

测试矩阵包含 Android 320×568、390×844、568×320、844×390，以及 WebKit 的 iPhone 竖屏和横屏。方向能力使用受控浏览器回调验证调用先后、拒绝回退和释放；触控布局、点牌、落子、配件盘、刷新与转屏使用实际浏览器页面。Chromium 的双指手势通过原生触控注入验证。物理屏幕旋转由实际设备及其系统授权执行。

首次准备测试浏览器可运行 `pnpm exec playwright install chromium webkit`；本地已有的独立浏览器目录也可沿用。桌面浏览器回归继续使用 `pnpm test:e2e`。

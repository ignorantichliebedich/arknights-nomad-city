# 合作企业板显示

八家企业使用项目已收录、与规则书核对的原版企业板。企业标识、品牌配色及黑底等级旗来自同一套印刷美术；页面顶部只在显示时截取企业板的抬头区域，完整牌面保持原样。等级说明使用可选取的网页文字，费用与奖励配上现有官方资源图标，玩家等级使用共用的立体影响力棋子和席位符号。

原始图集位于 `.data/sources/art/atlas-625.png`。依据 `manifest.json` 中的 `cropPixels`（左、上、右、下）提取八张 650×1850 原生分辨率企业板，保存到 `apps/web/public/assets/cards-625/0-hd.webp` 至 `7-hd.webp`。转换采用 WebP quality 96，保留原图尺寸。原缩略牌面继续用于棋桌配件入口；企业查看器和放大详情读取高清版本。

复建命令为 `python tools/prepare-enterprise-art.py`；脚本先校验原图 SHA-256，再按记录裁切并验证输出尺寸，更新来源、处理方法与文件哈希。运行 `pnpm assets:check` 可以核对全部运行图像。权属、原始公开地址与数字化来源沿用清单中的记录。

界面采用深灰框架、浅色纸面和企业自身的强调色。原版竖板位于左侧，0–5 级的可读说明与玩家标记在右侧，布局针对 1366×768 和 1920×1080 桌面窗口检查。正文与级别类型分别使用深色文字和加深的品牌色；玩家同时用颜色与符号区分，多人同级时排列到同一行的标记区。

企业效果来自既有 `ENTERPRISE_TEXT`，普通企业按牌面区分企业特效与升级奖励；莱茵生命使用同一份原版科室证据数据生成说明。切换查看玩家、企业和科室只改变本地预览；激活科室及实际合作等级跟随服务器状态。全体合作等级可展开对照，长昵称在玩家切换栏缩略显示、悬停可查看全文。减少动态效果设置沿用棋桌的统一行为。

## 2026-10-15：行动窗口中的企业档案

初始合作、升级与企业特效选择使用并列档案卡。卡面上部以 CSS 裁视同一份高清企业板的 650×320 品牌区域，企业标志与介绍按原比例呈现；原图文件及哈希保持不变。下部提供中文名称、合作方向和对应等级说明，完整原板通过独立详情按钮展开。四个选项在桌面窗口横向排列；更多选项在内容区滚动，底部确认按钮固定可见。

选中时描边、勾选标记和抬起反馈同时出现，并展开 1–5 级文字能力表。升级卡显示服务端给出的起止等级，同企业多个特效各自保留具体等级与说明。等级文字复用 `enterpriseLevels`，科室奖励跟随共享激活科室；选择、取消和查看详情均为本地预览，确认后提交原有合法指令。

行动、建设、事件、设施供应、结果、详情与日志窗口采用纸面、深褐标题框和黄铜边线；部署、调度、探索、城市移动与建设使用代码绘制的线条图标。窗口入场 260 毫秒，卡板悬停轻抬 3 像素，减少动态效果设置停用这两类动画。原生对话框保留 Escape、焦点限制以及关闭详情后的焦点恢复。

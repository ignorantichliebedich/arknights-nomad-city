# 《感染者》扩展

规则包 `oripathy-2024.1111`，以[官方 2024-11-11 规则书](https://web.hycdn.cn/arknights/boardgame/nomadcity/file/%E6%B8%B8%E5%9F%8E%E6%8B%93%E8%8D%92%E6%84%9F%E6%9F%93%E8%80%85-%E8%A7%84%E5%88%99%E4%B9%A620241111.pdf)及对应原版牌面为准。支持 2–4 人，自动包含企业扩展。首页创建房间时勾选“感染者”，再决定是否加入“企业家与抉择”。房间创建后固定配置；既有本体与企业扩展房间继续使用 `founders-2023.1`。

## 玩法与入口

- **常规玩法**：八位新增干员、阿米娅、三张流形、六张公共设施、三种城市样式、岩蹄安保、梅兰德基金会及新版罗德岛。
- **企业家与抉择**：在开局从末位玩家开始逆序选择身份；第 1、3、5、7 回合选择该回合抉择的 A／B 面。五位企业家与全部 40 种正反面效果分别处理。
- **查看资料**：地图旁“感染者档案”可切换玩家，查看企业家原牌、各轮抉择、声望／指令／收集标记、帮派储备、终身合约及授勋。马丁的建设图纸同时出现在设施供应窗口。
- **地图与城市**：棕色安保独立于四位玩家，帮派棋子使用紫色及所属玩家色旗；嘉维尔与区块锁定单独显示。城市格可查看叠层及下层牌面，公共供应显示各叠的上下层。
- **保密与恢复**：流形可在同一个盖放阶段额外秘密盖放；只有本人看见牌名。骰子、等待选择、持续效果、企业家限次标记与叠层随对局保存，刷新及服务重启后继续。

不存在全体玩家共用的新增“叠放”或“长途移动”行动。马丁叠建、嘉维尔指定资源点移动、艾格尼丝连续移动，分别依照企业家与角色牌处理。红区仍按四人第 4、三人第 5、两人第 6 回合开放。

规则书第 5 页基金投资费用举例的 A／B 名称与对应牌面存在交叉：第 3 回合 A“感染者协作”增加 4 金券费用及 2 声望，B“企业赞助商”增加一份基础资源费用及 1 声望。实现与测试按实际选择的原始牌面计算，合计费用一次支付。

## 配件与素材

官方规则书第 1 页合计 **63 张卡牌**：初始阿米娅 4、八位新增干员 8、流形 3、公共设施 6、城市化区域 9、额外核心指挥塔 1、企业家能力 5、企业家抉择 20、城市样式 3、授勋 4。PRTS 目录中的 71 张包含八张既有干员参考；清单将它们单独标为 `referenceFaces`，不作为八张新增实体牌加入牌堆。

原始出处：[官方桌游页](https://ak.hypergryph.com/boardgame_nomadcity/)、[PRTS 配件页](https://prts.wiki/w/游城拓荒：铸基者)、[官方拓荒指南](https://weibo.com/7499841383/OvI5A6Aps)、[公开数字化档案](https://steamcommunity.com/sharedfiles/filedetails/?id=3064722448)、[莫雷尔规则教程](https://www.bilibili.com/video/BV1T7pGe8Ewj/)（感染者部分约 21:56–28:38）。社区档案中同时存在民间改版，生产数据只使用和原规则书对应的组件。

规则书 SHA-256：`f6d57d308d91bb90abee199c527b8b60650119ee73d2b4eb604db543e2404a0d`。逐份来源、实体数量及原件摘要见 `assets/oripathy-evidence.json`。运行图像使用完整牌面、不放大原像素，归一化及摘要在 `assets/manifest.json`；图像与 PDF 原件均保留在忽略目录，水印沿用原件。

```powershell
python tools/research-oripathy.py
python tools/research-oripathy.py --check
python tools/import-oripathy.py
pnpm assets:check
```

第一条只下载清单登记的静态图像及官方 PDF，并校验文件头、大小和 SHA-256。第二条只核对本地缓存。第三条将已核验图像归一化到 `apps/web/public/assets/oripathy/`，保留原件。以上工具均不执行社区模组脚本。

## 验证与试玩

`tests/oripathy.test.ts` 覆盖全部新增角色的策略与计谋、全部企业家抉择正反面及关键时机；`tests/oripathy-invariants.test.ts` 按五种身份分别运行 2／3／4 人多分支整局，核对资源、实体设施、普通／帮派／安保供应与存档恢复。人机通过普通玩家视图参加新玩法，WebSocket 测试核对实际建房、重复提交与重启恢复。

本地入口 `http://localhost:3000`。建议先使用常规玩法熟悉新干员，再开启企业家抉择。验收重点为：查看和选择完整牌面、流形额外盖放、马丁叠建、安保采集、奇数回合抉择，以及刷新后接续待选步骤。发布按 `docs/release.md` 执行，源码推送与云端部署分开。

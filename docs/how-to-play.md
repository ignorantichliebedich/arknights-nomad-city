# 棋桌操作与对局恢复

> 版本说明：本页包括开发版操作。默认分支保留本体和企业扩展；感染者及新版返回交互见 [开发分支](https://github.com/ignorantichliebedich/arknights-nomad-city/tree/codex/oripathy-evidence)。

[返回项目首页](../README.md) · [本地运行](quickstart.md) · [感染者扩展](https://github.com/ignorantichliebedich/arknights-nomad-city/blob/codex/oripathy-evidence/docs/oripathy.md)

- 首页以纸质拓荒许可、四张原版企业家卡牌和暖褐荒野组成；可直接建房、填写房间码后回车加入，邀请链接会显示对应拓荒区。背景缓慢漂移，卡牌依次入场，系统减少动态效果设置会停用装饰动画。
- 房间大厅以四张企业家席位板展示立绘、城市棋子、本人／房主、在线与准备状态。点击空席或档案中的邀请按钮可分享房间；全员准备后由房主确认开始，离线玩家保留席位。页面显示准备进度、本局配置及棋盘缩略图。设计与素材复用见 [入口与集结桌](../assets/entry-lobby-art.md)。
- 房主可在“邀请朋友 → 人机同行”添加或移除人机席位；点击大厅空席也打开同一凭证。支持一位真人加 1–3 位人机，或朋友与人机混合组成 2–4 人对局。人机自动准备、选牌、行动和采集，各自计分，开局后锁定席位。策略使用正常玩家视图比较资源收益、建设和区域控制；人机不会读取其他玩家秘密手牌或牌库顺序。所有真人离线时暂停自动行动，恢复连接后继续已保存的待选步骤。
- 角色手牌在底部扇形展开，包含罗德岛招募的角色；悬停单张牌会抬起放大，鼠标离开扇面后自动收回，已选牌保留。移向确认区时扇面保持展开。点选后确认或双击卡牌即可盖放；所有玩家同时点选、预览和秘密盖放，最后一位确认后开始行动；左右方向键切换卡牌，回车选中，Escape 收起并取消本地预览。行动和事件从地图旁打开窗口。
- 顶部常驻“新手教程”和“功能查询”。六节教程提供选牌盖放、城市移动和采集路线的独立演示；查询可按关键词和类别检索操作、角色、设施与企业，牌文直接取自规则数据。教程练习与查看资料均不提交对局指令。
- “实操练习”与教程中的“进入实操教程”打开正式棋桌的独立练习场景，共七课：秘密盖放、影响力部署、城市移动、探索事件、设施建设、角色策略和并行采集。操作使用正式规则裁定，人机教练安排自己的选择；每课准备相应资源和地图场景，完成后亲自进入下一课。支持重练、退出及刷新后继续，进度仅保存在本机，不修改原联机房间。
- 房间码输入区与分享窗口采用通行凭证样式。加入房间、开始游戏时显示短过场，可按 Escape 或“跳过动画”结束；刷新与重连不重播。准备、加入、确认等按钮提供按下回弹反馈，网络等待期间阻止重复操作；系统减少动态效果设置会关闭按钮动画并缩短过场。
- 侧边资源盘与地图资源标记使用官方图标，数值增减带翻动提示。原版企业家立绘位于地图左侧，当前操作提示在立绘上方；大总统使用带底座、厚度与转动效果的立体立牌，跟随起始玩家。
- 回合末所有玩家同时规划采集，在地图逐点勾选、撤回并核对共用航道路费，选择收款方后锁定自己的方案。全员确认后才统一支付与领取资源；即使本次不采集，也需确认。探索和路费收款选择也在地图旁完成。
- 并行采集以进入该阶段时的金券为路费预算，本阶段收到的路费在全员确认后的结算中到账。这样每人的可选路线不受其他人确认先后的影响；结算日志按大总统起始顺序记录。这是本项目的联机流程约定，行动中角色能力触发的单人采集仍按能力顺序处理。
- 侧边显示每人的完成状态和全员确认进度；别人提交时保留自己的抬牌、路线与收款人预览。已确认玩家等待剩余席位，待选玩家断线时继续等待，重新进入原房间即可接续。
- 拖起自己的城市会显示可达位置，拖动时预览可达位置与费用，松手到合法目标即支付并移动；键盘和点选入口同时保留。分数标记沿地图边缘更新，每位玩家的回合有中央动画提示。
- 主要行动阶段可直接点击地图高亮位置或空格上的“＋”放置影响力；双击合法空位可直接确认。企业家立绘上方显示落点、空位和标记储备变化，点击“确认放置”后执行部署；改选、取消或 Escape 撤回均不消耗主要行动。待放置步骤刷新后也能从地图继续，原行动窗口入口同时保留。
- 可移动的影响力也可直接拖起，虚线圈标出全部合法空位，松手预览、确认落子；连续调度和中途刷新均能接续。无效落点或取消不提交指令。影响力使用带金属底沿与席位符号的立体棋子，实际转移时播放落位动画。
- 设施供应区可查看牌面并进入建设，依次选择城市格与付款方式。宣告时展示样式牌及实际使用的设施组合；建设、补牌和宣告结果停留到点击“继续拓荒”。
- 城市、设施与企业使用侧边缩略图打开，日志位于地图旁。原图上的回合和终局说明移到地图边缘，悬停展开、点击固定。棋盘支持全屏、100%–300% 缩放和空白处拖动，牌面详情支持继续放大。
- 城市详情以 3 列 × 4 行缩略盘展示实际格位；悬停建筑或用方向键移动焦点，旁边显示原牌面、效果与样式使用状态，点击可继续放大。窗口顶部可直接切换玩家，资源盘同步显示对应玩家的持有数量。
- 每位企业家下方常驻显示五种资源的官方图标和数量，分数单列；点击玩家打开其城市与资源。资源变化实时翻数，切换查看对象只切换余额。
- 合作企业窗口采用八家原版企业板与品牌配色，支持高清放大。0–5 级轨道显示全体玩家棋子，并区分企业特效、升级奖励和当前／下一等级；可切换玩家查看进度，展开全体等级对照。莱茵生命三个科室支持独立预览，当前激活科室始终单独标明。素材说明见 [合作企业板](../assets/enterprise-boards.md)。
- 行动、建设和结算窗口采用纸面与黄铜框，确认区固定在底部。选择合作企业时以官方品牌抬头组成并列档案卡，选中展开各级能力；升级及同企业的不同特效明确显示目标等级，完整原板可单独查看。
- 探索事件直接翻开原版事件卡，结果按钮并列放在卡面下方，使用官方资源图标。点击高亮选择，可取消或改选，确认后才结算；绿色、黄色与红色事件沿用牌面强调色，企业扩展自动展示对应替换卡。查看详情、关闭和刷新均不代选结果。
- 棋盘使用 5000×5000 原扫描，基础角色详情使用 1200×1700 原扫描，牌面按完整比例展示。
- 顶部合并为单行；棋盘去除原印刷边框与说明纸片，以 AI 地形补绘填充边角，原道路和交互坐标独立保留。桌面背景使用《铸基者》官网宣传图并轻微漂移，系统减少动态效果设置会关闭装饰动画。来源和生成提示见 [扇形棋桌素材记录](../assets/fan-table-art.md)。

- 每位玩家使用自己的浏览器或独立浏览器配置入座。无痕窗口可用于临时测试。
- 同一席位只保留一个活动标签页；在另一页打开该席位时，原页提示席位已转移。
- 开局后锁定席位。断线保留席位，等待其行动或选择，恢复连接后继续。
- 每条有效指令在 SQLite 事务中保存，再广播；重复编号返回已保存回执。普通行动校验房间版本，并行阶段另校验每人独立的选择版本：朋友提交不使自己的方案过期，本人改选或阶段结束后旧选择失效。
- 手牌、秘密盖放角色、秘密选择和私人日志按玩家投影，牌库顺序及随机状态留在服务端。
- 服务重启后使用原浏览器和原房间地址恢复。浏览器清除站点数据会清除该浏览器的席位凭证。
- 存档记录规则版本；升级服务时保留旧版本的代码或容器，以便继续既有对局。

默认数据库为 `.data/state/nomad-city.sqlite`，默认备份目录为 `backups/`。

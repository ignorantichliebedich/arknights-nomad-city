# 全屏与声音

每个标签页首次访问显示“全屏体验更佳”启程提示。点击“全屏体验”才申请浏览器全屏；“取消”或 Escape 直接进入游戏。提示关闭后，本标签页刷新、进房和重连不再重复。浏览器拒绝全屏时可取消继续。棋桌上的全屏按钮仍可随时切换。

顶部“声音”打开声音与音乐设置：全部静音、总音量、操作音效开关及音量、试听、背景音乐开关及音量。设置保存在本机 `nomad:audio:1`。首次交互前不会播放声音；系统减少动态效果设置与声音开关独立。

9 个明日方舟原版短音效总计约 55 KB，按点选、确认、盖放、弹窗、收回、提起、移动、建设、结算、探索和回合切换映射。地图拖动预览与服务端确认落子分别反馈，刷新载入既有状态不重播结算。最多同时 4 个声音，连续点击合并，加载失败不影响操作。原文件及压缩摘要见 `assets/audio-manifest.json`。

## 本地背景音乐

初版使用用户提供的 5 首 MP3，按下列顺序播放，总计约 15 分钟：Misty Memory (Night Version)、See You Soon、Il Signore del Carnevale、『雅赛努斯复仇记』、Speed of Light。

原件保存在项目根目录 `music/`，运行文件保存在 `apps/web/public/audio/music/`。英文文件名用于稳定地址，曲名仍在界面完整显示。导入仅复制，不重新压缩；大小、时长、输入文件名和 SHA-256 记录在 `assets/music-manifest.json`。

```powershell
pnpm music:import
pnpm music:check
pnpm build
```

音乐默认关闭，顶部“声音 → 背景音乐”开启。可以选择曲目、上一首、下一首、顺序循环或单曲循环；顺序循环播完第五首回到第一首，上一首在开头回到末尾。曲目、循环模式、音量及开关保存在当前设备，更新后沿用已有选择。页面切到后台时暂停，返回时继续；播放失败可以重试或换曲。

音频服务支持单段字节读取、尾部读取及 HEAD，浏览器可按需加载长音轨。范围响应与无效范围处理依据 [RFC 9110 §14](https://www.rfc-editor.org/rfc/rfc9110.html#section-14)。

公开仓库包含曲目清单、摘要、导入脚本和播放器源码，原始 MP3 与运行 MP3 均由 Git 忽略。`pnpm assets:restore` 获取既有美术和操作音效；本轮音乐使用本地 `music/` 导入，不向云端请求本轮文件。

## 后续添加曲目

规范入口是将原件放进 `music/`，在 `assets/music-manifest.json` 增加摘要及文件信息，再执行导入。运行清单 `apps/web/public/audio/music.json` 由脚本生成，结构如下：

```json
{
  "tracks": [
    { "id": "frontier", "title": "拓荒之旅", "src": "/audio/music/frontier.mp3" }
  ]
}
```

播放器支持 mp3、ogg、wav、m4a；本轮导入脚本接收清单指定的 MP3。`id` 使用 1–60 位字母、数字、下划线或连字符，最多 30 首。仅接受同源 `/audio/music/` 目录中的文件，不接受远程、脚本、带凭证或带查询参数的地址。列表为空时音乐开关显示“暂无曲目”。音量独立于操作音效。

本地修改后重新构建，先推送 GitHub 并由用户本地试玩。用户明确确认该版本上线后，运行音乐随同一部署包进入云端镜像；按 [发布流程](release.md) 验证，避免单独替换容器里的文件导致版本与素材不一致。

## 本轮试玩

在本机打开 `http://localhost:3000`，从顶部“声音”开启背景音乐。声音设置底部显示 v0.2.0；可试听五首、切换循环方式，检查音效与音乐的音量，以及刷新后是否保留选择。手机可用同一局域网中的开发电脑地址访问 3000 端口，横放后检查触控控制。

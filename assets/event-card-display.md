# 探索事件卡显示

事件窗口以完整原卡为主体，结果按钮位于下缘；背景棋桌压暗并模糊，卡面无需侧栏即可阅读。最大展示宽度 720 像素，短窗口按高度缩小，确认区与选项同屏。卡面仍可点击查看完整详情。

图像复用 `manifest.json` 中的事件卡：绿色 `cards-154`、黄色 `cards-167`、红色 `cards-156`，保留 600×424 原比例与原文件。企业扩展的洞穴遗迹使用 `cards-167/11.webp`，采集平台残骸使用 `cards-156/6.webp`；具体牌面由服务端待选事件提供。来源、权属、处理参数和哈希沿用原清单。

按钮以浅纸色、金属底沿和事件自身的强调色呈现；资源图标复用现有官方配件。选择态同时使用描边、底色和勾选，悬停轻抬 2 像素，按下回落。揭牌入场 380 毫秒；系统减少动态效果设置停用位移与旋转。

可选结果直接使用服务器合法行动，费用不足的分支不会生成按钮。选中与取消只修改本地预览，确认才提交原指令；付费后需要移除影响力或升级企业时，继续既有待选流程。保留原生对话框的键盘焦点、Escape 关闭及详情返回焦点。

浏览器验证方法见 [本地验证](../docs/quickstart.md#验证)，界面示例见 [项目展示](../README.md)。
